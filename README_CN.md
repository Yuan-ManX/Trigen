## 什么是 Trigen？

**Trigen 取名源自 Tri(三维、三生万物) + Gen(Generate 生成)**。依托道德经**道生一，一生二，二生三，三生万物**的生成哲学，以用户提示词为初始原点，将几何体、材质、光照三大三维基础要素作为核心三元结构，由内置 Agent 自动完成解析建模、贴图匹配、光影调试、场景排布、动画生成全链路工作，在浏览器端实时渲染输出各类三维模型、艺术场景、数字资产。

**Trigen 是面向 3D 创作的全球首个开源 AI 智能体**。它将聊天内容、照片或草图转化为 FBX、OBJ、GLB 或 STL 格式的可打印 3D 模型，可直接在浏览器运行，并接入 Blender、Unity、Unreal Engine 等各类工具平台。用户无需任何 3D 经验，通过对话即可完成 3D 内容的创作与体验。


## 创新

- **对话式 3D 生成** — 首个以自然对话驱动 3D 资产生成的智能体。说话、传照片、投草图，Trigen 自主推理、规划并构建模型。
- **三元要素 Agent 编排** — 几何、材质、光照由单一自主 Agent 统一编排为三元结构，以一条连贯流程替代碎片化的手工管线。
- **零门槛创作** — 无需 3D 专业背景。网格拓扑、UV 展开、着色器图等细节被自然语言所封装。
- **浏览器原生运行** — 模型开箱即在浏览器中实时渲染，无需安装厚重桌面软件。
- **开放格式生态** — 原生导出 FBX、OBJ、GLB、STL，无缝衔接 Blender、Unity、Unreal Engine 及下游管线。

## 特性

- **多模态输入** — 文本提示词、照片、草图均可驱动 3D 生成。
- **内置 AI 3D 模型** — 一组精选 3D 生成模型已接入 Agent 运行时。
- **Agent 驱动编辑** — 通过对话对 AI 生成或用户上传的 3D 内容迭代：塑形、换贴图、调光、加动画。
- **浏览器实时预览** — 在网页原生工作空间中获得即时视觉反馈。
- **多格式导出** — 一键输出 FBX、OBJ、GLB、STL。
- **跨平台集成** — 资产可直接置入 Blender、Unity、Unreal Engine 等工具。
