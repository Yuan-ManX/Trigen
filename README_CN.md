## 什么是 Trigen？

**Trigen 取名源自 Tri(三维、三生万物) + Gen(Generate 生成)**。依托道德经**道生一，一生二，二生三，三生万物**的生成哲学，以用户提示词为初始原点，将几何体、材质、光照三大三维基础要素作为核心三元结构，由内置 Agent 自动完成解析建模、贴图匹配、光影调试、场景排布、动画生成全链路工作，在浏览器端实时渲染输出各类三维模型、艺术场景、数字资产。

项目面向开发者与三维创作者，提供开箱即用的智能生成能力、可视化预览面板与可二次开发的 Agent 调度模块，轻量化部署，纯网页运行，无需本地厚重三维软件。
